## Task 8
  Ruling: the `exit`-shadowing fix is the right approach but has a latent defect I verified. With `exit() { return ${1:-0}; }`, a setup.sh containing `exit 3` followed by ANY further line continues past the exit and `source` returns the status of the LAST command — so rc came back 0 and the module would be recorded as SUCCESSFUL despite failing. Demonstrated both ways: bare shadow → rc=0 (failure lost); sentinel-captured → rc=3 (correct). Test 20 passes only because its setup.sh is a single `exit 3` line with nothing after. Fix: capture the code in a sentinel and prefer it over $?. Also documenting the module contract that setup.sh should use `return`, not `exit` — the shadow is a safety net for a forker's mistake, not the intended path. Cost if wrong: three extra lines; lines after a stray `exit` still run, which is a mistake-path imperfection far less bad than killing a 40-minute destructive run.

## Task 21
  Ruling: FIX the Important finding — a failed post-hide `update-grub` is never retried. The keys are written to /etc/default/grub before `update-grub` runs; if that call fails, MODULE_FAILED is set and no success note is claimed (correct), and the menu stays visible (fail-safe). But on every later run `patch_kv_set` sees the keys already at their target values, reports `unchanged`, leaves `hidden_changed=0`, and the retry never happens — while the run reports clean. So re-running provably does NOT converge, which contradicts the design's central "re-running is safe and converges" premise. I weighed leaving it: the symptom is a visible GRUB menu, which the user would notice, and the manual remedy is one `sudo update-grub`. What tips it is that a user who notices and re-runs 90-dualboot gets a successful-looking run and the same visible menu — the module silently fails to self-heal. Fix by gating the retry on whether grub.cfg actually reflects the hidden settings (e.g. `set timeout_style=hidden`), not merely on whether /etc/default/grub was just changed. Cost if wrong: one extra grep and an occasional redundant update-grub.
